MetaWork

面向持久化、可治理 Agent 工作流的商业 AI Task OS。将自然语言需求转化为可持久化的任务与工作图，交付可验收的结果，而不是停留在一次聊天回复。

为什么用 MetaWork

持久工作

任务、工作图、结果、恢复事实和审计记录可跨进程重启保留。

受控执行

Planner 负责提出工作，ControlKernel 负责授权状态变化，Executor 只执行明确获批的尝试。

多端统一

Desktop、Web、TUI 与飞书客户端使用同一套版本化命令与事件平面，查看同一批任务与会话。

可解释路由

每个获批尝试都固定到配置版本以及完整的模型与权限绑定。
