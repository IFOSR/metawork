# 自动化能力测试题目集

本目录是一套自动化能力测试。请直接按以下方式使用：

- `tasks/` 是题目目录。文件名 `task-XX-*.md` 中的 `XX` 就是任务编号（01–12）
- `attachments/<任务号>/` 是该任务的附件目录；对应目录不存在即表示该任务没有附件

要求：

1. 按任务编号逐个完成任务。每题的产物按题目要求生成并保留在指定位置
2. 完成标准以题目描述为准，题目之外的信息不需要读取
3. 需要在本机执行命令、安装软件、起停进程的，按题目要求真实执行；
   需要用户确认的操作先向用户提出
4. 受阻的任务（需要确认、缺权限、网络不可达等）如实标注受阻原因，
   不要跳过不报，也不要在受阻时声称完成

全部任务处理完毕后，生成一份统计报告 `stats.md`，只记录事实，不做自评：

```text
| 任务 | 状态（完成 / 失败 / 受阻） | 产物路径 | 一句话结果 |
```

判分由用户完成，你没有答案，也不需要猜测对错。
