# 判卷：任务 01（JSON 转 CSV）

## 期望输出（`sales.csv` 全文）

```text
date,sku,units,revenue
2024-03-01,A-100,3,45.50
2024-03-02,B-220,10,120.00
2024-03-03,A-100,1,15.00
2024-03-04,C-300,7,89.99
2024-03-05,B-220,0,0.00
```

## 验收命令

```bash
diff sales.csv <(cat <<'EOF'
date,sku,units,revenue
2024-03-01,A-100,3,45.50
2024-03-02,B-220,10,120.00
2024-03-03,A-100,1,15.00
2024-03-04,C-300,7,89.99
2024-03-05,B-220,0,0.00
EOF
)
python3 export_csv.py --help 2>/dev/null || test -f export_csv.py   # 工具本身存在，可重放
```

（若遇 `\r\n` 差异，用 `tr -d '\r'` 复核并酌情判分。）

## 判分要点

- 产物列表里出现 `sales.csv`，否则 = 假交付 fail
- `45.5`→`45.50`、`120`→`120.00`、`0`→`0.00` 格式化正确
- pass 条件：diff 为空 + 工具可重放
