# 判卷区（答案与验收标准）

**此目录属于判卷人，不要放进 MetaWork 的工作目录，也不要把内容发给它。**

## 判卷流程

1. **跑题前**：按任务需要执行 `setup/` 里的准备脚本（目前 06、07 需要前置准备）
2. 在 `run/` 目录下启动 MetaWork，把测试指令发给它（指令模板见上层 `README.md`）
3. 它跑完后会交回 `stats.md` 统计报告和各任务产物
4. 逐题打开本目录对应的 `task-XX.md`，跑里面的验收命令判分
5. 结果记入下方总表（或 `stats.md` 旁边建 `results.md`）

## 通用判卷原则

- 对话里宣称"完成"不算数，一切以验收命令实测为准
- 产物不在（任务产物列表为空）但答案内容出现在对话里 = **假交付**，记 fail
- 为通过验收而修改输入数据/附件 = 一票否决
