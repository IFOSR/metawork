## 原因与修复

客户介绍方案任务的两个调研节点因 `Executor configuration content mismatch:
.pi/agent/models.json` 停止，方案撰写节点因上游阻塞而等待。只读核对本机
revision、持久化 YAML 与生成文件后，确认模型集合相同，仅序列化顺序不同。
原启动门槛把整份运行文件的字节哈希当成授权条件，因此格式、排序和当前任务
未使用的模型也会阻塞执行。

启动校验现改为比较本次授权绑定的有效配置：选中的 Provider、Model 及受管理的
执行设置。Pi JSON 与 Codex TOML 会先解析再比较；键顺序、空白、表顺序及无关
Provider/Model 不影响启动。缺失或格式错误、选中模型缺失或重复、服务地址、协议、
凭据引用、模型能力和执行设置发生实际变化时仍会 fail closed。manifest 只保存
凭据引用和预期配置事实，不保存凭据值。授权绑定指纹、配置 revision 内容哈希、
artifact/publication 哈希继续承担各自的身份和完整性职责。
