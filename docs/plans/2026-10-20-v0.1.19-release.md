# MetaWork v0.1.19 release plan

- Plan date: 2026-10-20
- Status: Completed
- Authorization: publish the current source as the next formal release after
  v0.1.18; exclude Windows.

## Scope

Synchronize root, Web and Desktop package/lock versions at 0.1.19 and publish
the current source. The release includes the semantic runtime configuration
verification fix, clearer execution and blocker presentation, and numbered
preview release tooling.

Publish macOS arm64, macOS x64 and Linux x64 Runtime/Planner archives plus the
Apple Silicon Desktop DMG through the existing GitHub Actions release path.
The Intel macOS Desktop DMG is deferred because this release was built and
accepted on the Apple Silicon native path. Do not publish Windows assets or
dispatch the Windows workflow.

## Gates

- Root type checks, focused tests and release consistency checks pass.
- Release source, package metadata and release notes are synchronized.
- GitHub Actions verifies Runtime/Planner signatures, source identity, hashes
  and Desktop payload identity before promoting v0.1.19 as latest.
- Windows remains at its existing published version and is excluded from this
  release.
