## 展示目标与实现

使用 `frontend-design` 和 `ui-ux-pro-max` 的信息层级与交互指南，沿用现有主题、语义色和字体，按概览、趋势/画像、管理明细组织内容。

账单展示当前账号的 Token 用量，不新增金额推算。统一时间和统计维度筛选区、累计/官方额度/自备模型汇总、每日趋势、图例和折叠明细；供应商说明独立换行。图例只改变趋势，汇总与明细保留完整口径；全部隐藏时提供恢复提示。日期检查限制有效起止和最多 366 天。刷新期间保留已有数据和稳定提示空间，失败显示实际错误并标明上次成功快照，支持重试。

记忆增加账号画像，展示总数、可使用数量、L1/L2/L3 分布、主要主题、信息类型及三条可打开原文的已保存摘要。优先展示可使用的 L3 画像和 L2 经验。主题只依据已保存标题与摘要的关键词归类，一条记忆可涉及多个主题；不调用额外模型，不生成未经记忆支持的人格判断。

画像独立于管理列表读取，每页 200 条、最多 10,000 条，包含停用记忆。搜索、筛选、列表翻页不会将局部列表误当作整体画像。重复记录去重；总数漂移、缺页或超出上限时明确标记部分内容。读取失败保留具体原因和重试入口，管理列表仍可操作；成功切换状态或删除后更新画像。保留原列表、详情、导出、停用和删除功能。
