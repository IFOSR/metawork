# MetaWork v0.1.5 Web and Desktop release

- Plan date: 2026-10-07
- Status: Internal release published; public signed release remains pending
- Goal: Publish the internal Server/Web/TUI runtime and an unsigned macOS Desktop
  DMG for company use, with matching English/Chinese README installation paths.

## Delivery

- Align Runtime, Web and Desktop version metadata to 0.1.5.
- Keep one Server and the existing installer/update authority. Remove the
  production Desktop installer's dependency on a developer's internal LLM files;
  optional internal AI remains unavailable until separately provisioned.
- Build macOS Desktop from the same signed Runtime/Planner archives as native
  installation. The internal package uses trusted release archives and native
  architecture verification, but intentionally omits Developer ID signing and
  notarization for company distribution.
- Validate all release assets before publishing a draft as latest. Installers
  and README downloads follow the stable release, not an unreleased main branch.
- Document Desktop, browser, TUI, Feishu, update and source-development choices.

## Acceptance

- Focused release/installer tests, type checks and local builds pass.
- Clean-machine installation succeeds without developer configuration.
- Native arm64 release assets and the internal Desktop build pass on this Mac.
- GitHub release assets match the internal release identity and downloadable README links.
- Record source/closing commits, completion date and published verification here.

## Current external prerequisites

- The internal release intentionally does not require an Apple Developer ID
  certificate or notarization profile.
- Production Desktop requires approved relocatable Node/Git/Pi distributions
  and Apple signing/notarization configuration; their locations are pending.
- Signed clean-machine, paid task and coordinated-update acceptance on both
  Mac architectures still require production payloads and native runners.
