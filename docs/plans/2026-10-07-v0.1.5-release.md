- Plan date: 2026-10-07

  DMG for company use, with matching English/Chinese README installation paths.

- Align Runtime, Web and Desktop version metadata to 0.1.5.

  optional internal AI remains unavailable until separately provisioned.

  and README downloads follow the stable release, not an unreleased main branch.

  identity follows package metadata instead of a hard-coded version.
- README and README.zh-CN distinguish Desktop, Web, TUI, Feishu and source
  installation, latest stable versus unpublished source, and update paths.
- Release workflow prepares both macOS DMGs from the native signed archives,
  imports signing credentials in an ephemeral keychain, notarizes/staples,
  runs a packaged clean-install smoke and signs DMG download manifests.

  execution still requires the CI runner.
