# MetaWork v0.1.17 release plan

- Plan date: 2026-10-16
- Status: Completed (internal release)
- Scope commit: `2f384526` plus release metadata and documentation

## Release scope

This release delivers the task execution user-state convergence work from
`2026-10-16-task-execution-user-state-convergence-plan.md`, including durable
acceptance of safe uncertified results, deterministic rechecks before delivery,
and removal of internal blocked wording from user surfaces. It also carries the
post-v0.1.16 official account settlement/refund work and related installation,
configuration, session and Web fixes already merged to `main`.

## Required gates

- Root, Web and Desktop package and lock versions are `0.1.17`.
- `npm run lint`, focused task-state tests, release consistency tests, Web build
  and Desktop build pass.
- The tagged GitHub Actions workflows build and sign all four Runtime/Planner
  targets and both macOS Desktop DMGs. The macOS/Linux workflow publishes the
  stable Release first; Windows is built by the separate `v0.1.17-windows`
  workflow and uploaded to that stable Release without blocking DMG creation.
- Clean packaged installation, authenticated Web/Server survival, occupied-port
  startup, failed update recovery and interrupted update recovery pass on both
  macOS architectures.
- Release manifests, archive hashes, Desktop manifests, installers and the
  published `latest` aliases verify byte-for-byte from GitHub.
- README and README.zh-CN download links resolve directly to `v0.1.17`.

## Completion record

- Source commit: `154a8139` (`fix(pdf): use cross-platform cryptography wheel`).
- Runtime workflow: GitHub Actions run `38913063561`; macOS arm64, macOS x64 and
