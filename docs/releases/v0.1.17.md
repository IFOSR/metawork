# MetaWork v0.1.17

**Release tag:** `v0.1.17`

## Delivered changes

- Task surfaces now use four user states: waiting, executing, needs action and
  finished. Internal `blocked`, `block_work` and `awaiting_decision` facts remain
  available for recovery and audit without being shown as user status labels.
- Safe PDF/PPT and other file results that lack completion evidence are retained
  for an explicit **accept and deliver** or **re-execute** decision. Acceptance
  rechecks Attempt, result identity, file safety and publication prerequisites.
- Tasks without a safe result finish with an actionable execution failure and a
  new execution path instead of remaining in an internal blocked state.
- Official account payment settlement and refund handling, plus the latest
  configuration, installation, session and Web build fixes, are included in the
  coordinated Runtime/Web/Desktop release.

## Release artifacts

This internal release contains Runtime and Planner archives for macOS arm64,
macOS x64 and Linux x64, plus an Apple Silicon Desktop DMG. The DMG uses an
internal ad-hoc signature and is not Apple notarized. Windows is intentionally
deferred to the separate `v0.1.17-windows` tag and workflow.

The Runtime manifests and archive hashes were verified in GitHub Actions run
`38913063561`. The DMG passed `hdiutil verify`, strict ad-hoc code-signature
verification and SHA-256 validation locally.
