# MetaWork v0.1.5 Release

**Release tag:** `v0.1.5`

**Channel:** `stable`

**Publication status:** Prepared in source; publication and signed Desktop
acceptance are pending. Do not treat this file as proof of an available release.

## Included installation choices

- Server with the production Web UI, native TUI and optional Feishu integration:
  macOS Apple Silicon/Intel, Linux x64 and Windows x64.
- macOS Desktop for Apple Silicon and Intel: signed and notarized DMGs containing
  the same Server/Web/Planner release plus relocatable Node, Git and Pi Executor.
- All clients use the same Server for the selected installation/account.
  Desktop development continues to use a separate isolated installation.

## Changes

- Electron Desktop provides local login, native directory/artifact dialogs,
  persistent drafts, notifications and controlled installation/update actions.
- Ordinary Agents use the unified standard permission baseline; settings remain
  draft-based with one save-and-activate action.
- Pi includes a pinned PDF interpreter and dependencies for bounded extraction
  and rendering. Windows uses its native Python executable layout.
- Fresh Desktop installation no longer requires a developer's internal LLM
  credentials. Manual settings and task configuration work independently;
  optional internal AI functions require separate provisioning.
- Release publication requires all native archives, both Desktop DMGs and their
  signed download manifests before latest is changed. Published releases are
  immutable; failed builds leave the previous latest release intact.

## Install and update

Choose Desktop or Server/Web/TUI in the [README](../../README.md#installation)
or [中文说明](../../README.zh-CN.md#安装方式). Download links follow GitHub's
latest stable release. The release includes `install.sh`, `install.ps1`,
`MetaWork-darwin-arm64.dmg` and `MetaWork-darwin-x64.dmg`.

Stop Server before updating a CLI-managed installation. For Desktop-managed
installations, use **安装新版应用… / Install New Application…** to update the app
and Runtime together. Configuration, credentials and account data are retained
by the existing update transaction.
