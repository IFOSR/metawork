# MetaWork v0.1.3 Release

**Release tag:** `v0.1.3`

**Release date:** 2026-10-03

**Channel:** `stable`

MetaWork v0.1.3 is the formal stable release of the current
Server/Client Gateway architecture and multi-client observation model.

## Highlights

- Web, Feishu, and the native MetaWork TUI share one observation protocol and
  can follow the same Conversations and Tasks.
- Conversation switching uses durable, bounded read models and indexed activity
  projections, so a client can show history without replaying a complete
  session or attaching another executor.
- The native TUI keeps the existing left-side execution view and adds a task
  dashboard for running, queued, and blocked work across Conversations.
- The Web Conversation view preserves execution progress, generated reports,
  billing cards, complete message content, and the revised trajectory layout.
- Explicit navigation targets, bounded trace pages, task-to-Turn location, and
  reconnect generation guards keep late responses from changing the active
  Conversation or draft.
- Gateway permissions, cancellation, approvals, Feishu delivery, and
  multi-client control continue to use the existing durable authorization
  contracts.

## Native release matrix

| Target | Artifact platform | Availability |
| --- | --- | --- |
| macOS Intel | `darwin-x64` | Prebuilt |
| macOS Apple Silicon | `darwin-arm64` | Prebuilt |
| Linux x64 | `linux-x64` | Prebuilt |
| Windows x64 | `win32-x64` | Prebuilt |

Every target publishes a Runtime archive, a vendored AnyFusion-Pi Planner
archive, and an Ed25519-signed manifest. The stable installer verifies the
manifest signature, release identity, compatibility block, archive sizes, and
SHA-256 hashes before installation.

Linux arm64 remains a native build target. It is not included in this
prebuilt release because `better-sqlite3` must be built for the target host.

## Installation

macOS, Linux, and WSL2:

```bash
curl -fsSL https://14.103.216.193/metawork-release/install.sh | bash
```

Windows x64:

```powershell
irm https://14.103.216.193/metawork-release/install.ps1 -OutFile metawork-install.ps1
.\metawork-install.ps1
```

Both installers default to the `stable` channel and resolve the signed
`v0.1.3` artifacts from the `latest` installation pointer. Existing
MetaWork installations are updated in place while configuration, secrets, and
task data are preserved.

## Compatibility

The `metawork`, `anyfusion`, and `metaclaw` command names remain available.
Existing `~/.anyfusion` installations migrate transactionally to
`~/.metawork`; durable compatibility identifiers are preserved.
