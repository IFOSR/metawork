# MetaWork v0.1.22 (Internal)

**Release tag:** `v0.1.22`

Internal build. Not submitted to the App Store and not Apple-notarized.

## Fixes

- Desktop installs and upgrades ship the bundled long-term memory engine again.
  The upgrade path passed no memory root at all, and the clean-install path
  passed the engine's parent directory, so the installed release contained either
  no `memory/tdai` or a doubly nested copy. Long-term memory therefore reported
  that the engine was not installed, while Web and CLI installs were unaffected.
- Both Desktop entry points now resolve payload paths through one helper, and
  release staging rejects a memory root that is not the engine directory, so a
  wrong layout fails during installation instead of shipping a memory switch that
  can never work.
- Desktop upgrades no longer deadlock. The Desktop shell launched the Runtime with
  the retired `METACLAW_EXECUTOR_BACKEND=in_place`, which the Runtime refused, so
  the candidate server never became ready, the update rolled back and the recovery
  screen looped. The shell now sends `native`, and the Runtime accepts `in_place`
  as a deprecated alias of `native` so a machine still running the older shell can
  complete the upgrade.
- Planning no longer deadlocks on a configuration revision it cannot express. A
  rollback wrote an activation id with dots and 69 characters; the Planner had to
  declare it verbatim while the proposal schema forbade it, so every task-like
  request ended with "planning budget exhausted" after five rejected retries.
  Revision ids are now generated inside the configuration reference grammar,
  `ConfigurationService` rejects a bad id at creation, the Runtime supplies
  `workGraph.configurationRevision` instead of asking the model to copy it, and a
  rejection that repeats verbatim stops the turn with its cause named.
- Includes everything from v0.1.21: stalled tool-call interruption, Workspace
  scoped scheduling capacity, mandatory `workspaceEffect` declarations,
  per-Turn execution records with trajectory history, and deleted-Conversation
  cleanup that no longer fails a whole Workspace.

## Downloads

- Apple Silicon Desktop: `MetaWork-darwin-arm64.dmg` (ad-hoc signed; on first launch
  allow it in Finder or run `xattr -dr com.apple.quarantine /Applications/MetaWork.app`).
- Signed Runtime/Planner/Memory archives for macOS arm64, macOS x64 and Linux x64,
  each with its signed manifest.
- `install.sh` for the Runtime archives.

## Deferred

- Intel macOS Desktop DMG (`MetaWork-darwin-x64.dmg`) is not published in this
  release; the macOS x64 Runtime archives are.
- Native Windows release and `install.ps1` are not published in this release.
- Container images are published by a separate workflow and are not part of this
  release.
