# MetaWork v0.1.21 (Internal)

**Release tag:** `v0.1.21`

Internal build. Not submitted to the App Store and not Apple-notarized.

## Changes

- Executor interrupts a stalled tool call. A call is judged stalled only when its
  output, its own process subtree's CPU time and the workspace writes all stop for
  five minutes; the guard terminates that call's process group, hands the failure
  back to the model as a tool error, and ends the Attempt with an explicit failure
  after three interruptions instead of hanging until the user kills a process.
- Schedulers no longer apply account-wide Task/Attempt gates. Capacity is bounded
  per Workspace by a Conversation limit, and a Task runs up to 10 Attempts
  concurrently, so independent read-only research roots actually run in parallel
  instead of queuing behind one write lease.
- Planner declares `workspaceEffect` for every Subtask. Plan validation requires it
  when a graph has two or more text-only report roots, and a graph that leaves
  available parallelism unused records that fact.
- Every Conversation Turn keeps its own execution record. Subtask cards name their
  execution state (`已完成` / `执行中` / `等待中` …), a settled Turn keeps a
  collapsible DAG instead of losing it when the next Turn starts, and the
  trajectory surface can walk back through every Turn — including a Turn that left
  the bounded client window, which is now read by identity from the server.
- Deleting a Conversation erases its derived projection work and no longer fails
  the whole Workspace root, so a deleted Conversation can no longer block new
  Conversations. Workspace Git recovery treats sealing, publication and merge
  notifications as Conversation-scoped work, and reports the real cause
  (`workspace_git_<state>: <reason>`) instead of an opaque `workspace_unavailable`.

## Downloads

- Apple Silicon Desktop: `MetaWork-darwin-arm64.dmg` (ad-hoc signed; on first launch
  allow it in Finder or run `xattr -dr com.apple.quarantine /Applications/MetaWork.app`).
- Signed Runtime/Planner/Memory archives for macOS arm64, macOS x64 and Linux x64,
  each with its signed manifest.
- `install.sh` for the Runtime archives.

## Deferred

- Intel macOS Desktop DMG (`MetaWork-darwin-x64.dmg`) is not published in this
  release; the macOS x64 Runtime archives are.
- Native Windows release and `install.ps1` are not published in this release.
- Container images are published by a separate workflow and are not part of this
  release.
