# MetaWork v0.1.31 (Internal)

**Release tag:** `v0.1.31`. Internal build: the Apple Silicon DMG is ad-hoc
signed and not Apple-notarized. Intel DMG and Windows packages are not published.

## Execution

- Fix a startup failure path where shared read-only Workspace preparation could
  throw before the Subtask entered `running`, causing failure settlement to hit
  the terminal fence and leave an uncertain dispatch without a receipt.
- Enter `running` immediately after claiming the Attempt, before asynchronous
  preparation. Preparation failures now preserve their original error and
  no-Executor-launch facts through the existing terminal transaction and release
  resource and conversation claims.
- Only explicitly transient preparation errors use the existing bounded
  continuation budget. Workspace safety checks, cancellation and terminal fences
  remain enforced. If settlement itself fails, redacted diagnostics retain both
  errors; an unknown execution outcome is not treated as safe to rerun.

## Verification and limits

- The fix has 17 focused regression tests; 114 related execution tests, lint and
  full build passed before release preparation.
- Local macOS arm64 + real Admin Web acceptance completed a normal four-node
  graph and the same graph with one injected `EBUSY` preparation failure. Only
  the failed node retried automatically; both Tasks completed and released their
  resources. See [the implementation record](../plans/2026-11-15-attempt-startup-failure-landing.md).
  That acceptance used a local preview with Pi 1.5.2; the release retains the
  repository's locked Pi 1.5.0 rather than introducing a Pi upgrade.
- The maintained-host suite retains five previously recorded failures in
  permission/read-only boundary fixtures; it is not reported as fully green.
- Release checks passed for version consistency, lint, the 17 startup-failure
  regressions, and native Manager/Executor processes with locked Pi 1.5.0.
- All three CI Runtime targets built successfully; archive signatures, hashes,
  sizes and source revision verified. The mounted DMG passed image and app-seal
  checks and upgraded the installed preview through the real Desktop updater in
  a disposable installation, including the bundled Memory engine.
- Three existing Desktop release-fixture tests still fail because their mock
  payload lacks required Pi files, matching the recorded November 12 baseline.
- Clean installation from the mounted DMG passed with an isolated home and
  restricted PATH: authenticated Web, settings activation without restart,
  failed-probe rollback, menu, reload, bundled Pi, and Server survival on app
  exit. The temporary smoke script used current model-binding requirements and
  omitted removed model-pricing fields; the repository's older smoke script
  still needs those fixture updates. This check made no paid model requests.
- Linux and Intel Server archives are built, but complete user acceptance is
  scoped to macOS arm64 + Web. Historical uncertain rows without receipts still
  require evidence-based review; this release does not bulk-clear them.
- Release artifact identity, hashes and Desktop upgrade-gate results are recorded
  in [the release record](../plans/2026-11-16-v0.1.31-release.md).
