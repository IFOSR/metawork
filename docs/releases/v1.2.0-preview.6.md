# MetaWork v1.2.0 Preview 6

**Release tag:** `v1.2.0-preview.6`

**Release date:** 2026-09-30

## Highlights

- macOS Intel (`darwin-x64`) release packaging.
- macOS Apple Silicon (`darwin-arm64`) release packaging.
- Windows x64 (`win32-x64`) native package with PowerShell installation.
- Linux x64 and arm64 build targets prepared for Linux-host or CI builds.
- Signed Runtime and vendored AnyFusion-Pi Planner artifacts remain verified
  by the existing manifest trust chain.

## Build Matrix

| Target | Build location | Artifact |
| --- | --- | --- |
| macOS Intel | macOS Intel or compatible CI runner | signed Runtime + Planner archive |
| macOS Apple Silicon | macOS arm64 or compatible CI runner | signed Runtime + Planner archive |
| Windows x64 | Windows x64 or compatible CI runner | signed Runtime + Planner ZIP |
| Linux x64 | Linux x64 host or CI runner | signed Runtime + Planner archive |
| Linux arm64 | Linux arm64 host or compatible CI runner | signed Runtime + Planner archive |

Linux artifacts are not cross-faked from macOS because `better-sqlite3` and
other native dependencies must be installed for the target operating system.

## Upgrade Notes

- Windows uses named pipes for local Gateway and Planner Host connections.
- The Unix `install.sh` path remains for macOS and Linux. Windows uses
  `scripts/install.ps1`.
- A real release signing key is required for publication. Development keys are
  only for local verification and must not be published.

## Validation

- `npm run lint`
- `npm run build`
- focused release and installer tests
- full Vitest suite on the supported local environment

## Installation Server

The signed Preview 6 assets were published to the one-command installation
server after GitHub Release publication. The `latest` pointer now serves
`1.2.0-preview.6-build-aebea7b` for all four native targets, together with
`install.sh` and `install.ps1`. Future Release publication invokes the same
deployment workflow, which verifies the complete asset set and public HTTPS
downloads. Signed manifests and archive hashes are checked before switching
`latest`; a failed post-switch HTTPS check restores the previous pointer and
installer entry points.

The October 1, 2026 rebuild installs the target-native `better-sqlite3`
binary in every Runtime archive. Existing installations can use the same
`install.sh` or `install.ps1` entry point to update in place.
