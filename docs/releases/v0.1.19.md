# MetaWork v0.1.19 (Internal)

**Release tag:** `v0.1.19`

## Fixes

- Runtime launch validation now compares the authorized Pi/Codex configuration
  semantically. Model ordering, formatting, and unrelated catalog entries no
  longer block execution.
- Changes to the selected Provider, Model, service endpoint, protocol,
  credential reference, model capability, or managed execution setting still
  fail closed.
- Execution cards and notices now make waiting, executing, completed, and
  upstream-blocked work easier to distinguish, including the affected subtask
  and the next available action.
- Preview release identities use the ordered SemVer form `-preview.N`.

## Downloads

- `MetaWork-darwin-arm64.dmg`: self-contained Apple Silicon Desktop.
- Signed Runtime/Planner archives: macOS arm64, macOS x64 and Linux x64.
- `install.sh`, signed Runtime manifests and GitHub asset SHA-256 digests.
- Windows is excluded from this release; no Windows artifact or Windows
  workflow was published. An Intel macOS Desktop DMG is also deferred because
  this release was built and accepted on the Apple Silicon native path.

The Desktop DMG follows the existing internal release path: ad-hoc signed and
without Apple notarization. Install the DMG and complete the in-app service
update before resuming affected tasks.

## Validation

Focused configuration, execution-state, release and installation tests pass;
the Runtime assets and Apple Silicon Desktop payload are verified against the
source commit before publication. Final CI runs, asset hashes and Desktop
acceptance evidence are recorded in the completed release plan.
