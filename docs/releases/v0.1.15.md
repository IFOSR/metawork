# MetaWork v0.1.15

**Release tag:** `v0.1.15`

## Internal reliability update

- Keep an already-authorized sibling Attempt valid while another Subtask is waiting or being handled.
- Preserve Executor probe failures as structured environment failures instead of reporting them as capacity exhaustion.
- Treat Executor capacity as a scoped Subtask wait when another independent branch is still executing.
- Allow a capacity timer to recheck a Task that remains running while a sibling branch completes.

This local build is an internal macOS Apple Silicon validation release. The
current real task still requires an active MetaWork official account session
before Gateway recovery can be tested.
