# MetaWork v0.1.18 (Internal)

**Release tag:** `v0.1.18`

## Fixes

- Custom Pi/Codex AgentClasses can read authorized upstream results in multi-stage tasks.
- Affected tasks that failed with missing upstream input can resume explicitly once
  the input is proven available. Completed stages and original results are retained.
- Replanning validates exact evidence references; startup recovery no longer mistakes
  waiting-for-decision work for orphan execution. Existing evidence references remain valid.
- Desktop reconnect and interrupted upgrades recover safely when an owned macOS
  Server process stalls after shutdown. Task status presentation is unchanged.

## Downloads

- `MetaWork-darwin-arm64.dmg`: self-contained Apple Silicon Desktop.
- Signed Runtime/Planner archives: macOS arm64, macOS x64 and Linux x64.
- `install.sh`, signed Runtime manifests and SHA-256 checksums.
- Windows is excluded from this release. macOS x64 and Linux use Web, TUI or Feishu
  with the Server package; they do not include a Desktop application.

The Desktop DMG follows the previous internal release: ad-hoc signed, without
Apple notarization. Install the DMG and complete the in-app service update before
resuming an affected task in its original conversation.
