# MetaWork v0.1.16

Published 2026-10-16 from the tagged source commit.

## Delivered changes

- Conversation Markdown now renders GFM tables as accessible tables with visible borders, header styling, column alignment, keyboard horizontal scrolling and authorized artifact links.
- Data-backed answers can include bounded local `chart` JSON for line, bar, area and pie charts. Charts preserve missing and negative values, include legends, tooltips and an accessible data table, and support light/dark themes and responsive layouts.
- Web clients can export chart SVG. Desktop clients can save chart PNG through a native destination dialog with strict payload validation, pixel re-encoding and atomic writes.
- HTML, DOCX, PPTX, XLSX/XLS/CSV and PDF previews run locally in a sandboxed document drawer.
- Task execution reliability, explicit file-delivery semantics, managed Executor recovery, routing and rich observation fixes are included in the coordinated Runtime/Web/Desktop release.

## Release artifacts

The release workflow builds and verifies signed Runtime and Planner archives for macOS arm64, macOS x64, Linux x64 and Windows x64, plus signed/notarized Desktop DMGs for both macOS architectures. `install.sh` and `install.ps1` are published with the verified release set.

The release workflow performs focused tests, clean packaged installation checks, document preview checks, chart/table rendering checks and coordinated update recovery checks before promoting `v0.1.16` as latest.
