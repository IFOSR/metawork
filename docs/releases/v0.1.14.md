# MetaWork v0.1.14

Published 2026-10-11. This release corresponds to source commit
`1b2543465380b9fdef6af62c3a68a9529232d378`.

## Downloads

- macOS Apple Silicon Desktop DMG: `MetaWork-darwin-arm64.dmg`
- macOS arm64 Runtime and Planner archives
- Linux x64 Runtime and Planner archives
- Windows x64 Runtime and Planner archives
- Signed platform manifests and `install.sh` / `install.ps1`

The Desktop DMG is an internal ad-hoc signed, non-notarized package. Desktop is
available for macOS Apple Silicon. Server/Web/TUI installation is available for
Linux x64, macOS arm64, and Windows x64.

## Delivered changes

- Unified decision-model routing across Planner, AgentClass, and Model selection.
- Provider-based decision-model configuration using the System One protocol.
- Manual model-information fallback for models missing from the OpenRouter catalog.
- Visible attachment and screenshot indicators in conversation turns.
- Structured Executor failure diagnostics, blocker reasons, retry state, and recovery guidance.
- Compressed self-contained Desktop packaging.
