# MetaWork v0.1.26 (Internal)

**Release tag:** `v0.1.26`

Internal build. The Apple Silicon Desktop is ad-hoc signed and is not Apple-notarized.

## Fixes

- Restore the Executor's extension tools. Pi's `--tools` flag is a global
  allowlist that also covers extension-registered tools, so deriving it from the
  Executor affordance projection removed `web_search`, `web_fetch`,
  `evidence_*`, `result_reference_list/get` and the `pdf_*` tools from every
  Attempt since 2026-10-28. Executing Attempts now launch with Pi's complete
  registry, and affordances only decide what gets materialized.
- Dependent Subtasks can read authorized upstream results again instead of
  improvising with shell workarounds. The 2026-11-05 incident spent 26 minutes
  scanning 190 GB of account data with `grep` for an upstream result that
  `result_reference_get` returns directly.
- The response-only completion correction entrypoint now runs with no tools and
  no durable session (`--no-session --no-tools`). Its contract is one completion
  trailer and no action, and its prompt already forbids executing the task.

`workspaceIntent` and read-only Workspace boundaries still never shrink a normal
Attempt's tool surface; that behaviour is unchanged from v0.1.25. ADR-0052
carries a dated amendment recording why launch-time tool allowlists are no
longer used.

## Validation

- `npm run lint` (tsc --noEmit) and `npm run build` pass.
- 95 test files / 701 tests in `tests/executor` and `tests/execution` pass,
  including a regression test asserting that a launched Attempt never carries a
  tool allowlist even when the Executor publishes affordances.
- The full suite still reports 52 failures, unchanged from the pre-existing
  baseline: they are source-text assertions and stale spy expectations in
  `tests/e2e`, `tests/session`, `tests/web`, `tests/account` and
  `tests/acceptance`. Re-running two of them on a clean tree reproduces the same
  failures, so they are not caused by this change.
- Isolated Desktop upgrade check: the packaged payload's
  `dist/server-composition-*.js` contains the new response-only launch and no
  longer contains the affordance-to-allowlist branch.

## Downloads

- Apple Silicon Desktop: `MetaWork-darwin-arm64.dmg`.
- Server installers for `darwin-arm64`, `darwin-x64` and `linux-x64`, with
  Runtime/Planner/Memory archives and signed manifests.
- Intel Desktop DMG, Windows packages and container images are not included
  in this internal release.
