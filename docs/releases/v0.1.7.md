# MetaWork v0.1.7 (Internal)

**Release tag:** `v0.1.7`

> **升级注意（2026-10-08）：** 此内部版存在 Desktop 升级失败后的修复流程缺陷，可能反复提示“修复未完成的更新”。并非每次升级都会失败，但暂不建议将 v0.1.7 推广用于客户升级。已正常使用的安装无需回退；遇到循环请保留安装目录和数据，停止重复修复，等待包含修复的新版本。不要删除升级记录、数据库或手动切换版本目录。
