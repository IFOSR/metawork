# MetaWork v0.1.6 (Internal)

修复已安装 Web/TUI Runtime 的用户首次打开 Desktop 时无法进入的问题。

- 相同版本直接接入现有账户与 Server，自动补齐 Desktop 工具。
- 较旧 Runtime 显示“升级并接入已有数据”，保留配置、凭据与历史数据；支持历史 1.2.0-preview 版本。
- 修复 macOS Preferences 路径冲突及升级时 app.asar/框架符号链接复制问题。

Apple Silicon (arm64) 内部 DMG，沿用 v0.1.5 的内部分发签名密钥；未进行 Apple Developer ID 签名或公证。安装方式见 README。
