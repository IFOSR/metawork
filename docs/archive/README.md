# 归档（历史材料，非权威）

本目录保存历史计划、已完成或被取代的方案、事故复盘与旧版技术文档，用于追溯"当时为什么
这么做"。它与现行实现**刻意隔离**：

- 不更新、不修复链接、不作为实现或评审依据。
- 其中的文件名、模块路径、环境变量名（`METACLAW_*`、`AnyFusion`）、Kernel/Codex/Docker
  等被删除的概念都可能已经不存在。
- 需要历史结论时，引用现行权威文档（[`../README.md`](../README.md)）中的对应条目，而不是这里。

（模块、后端、协议）已从代码中移除。
